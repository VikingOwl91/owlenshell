## Reading the classifications

- **IMPLEMENTED:** source mechanism exists at this baseline; runtime/production acceptance is not implied.
- **EXPERIMENTALLY VALIDATED:** a preserved report supports a declared experimental source/environment/scenario, not automatic migration into this application.
- **PARTIAL:** some mechanism or scoped coverage exists, with material missing behavior.
- **PLANNED:** proposed functionality without a current implementation.
- **UNVERIFIED:** the specified behavior has insufficient runtime evidence.
- **BLOCKED:** a stated prerequisite/environment prevents the specified evaluation. Missing tests alone are not FAIL or BLOCKED.

A row may have IMPLEMENTED code and UNVERIFIED runtime behavior. Tests listed as source references describe coverage, not independent visual proof. The fresh automated result below is separate.

## Fresh validation and its boundary

At this baseline, `cargo test --locked --offline` completed with **115 passed, 0 failed, 0 ignored** in private HOME, XDG state/config/cache/runtime and temporary directories, with display, compositor and session-bus socket variables unset. An existing owned build cache was reused, with two jobs and the inherited compiler wrapper disabled. No shell application, upstream code, compositor or system service was launched. These tests cover current Rust logic/mocks; they do not validate live Wayland buffers, pixels, focus, physical outputs or production acceptance.

The first invocation isolated displays/build outputs but not default state paths. An existing drag test reaches `Placements::save()` through `Coordinator::finish_drag` ([tests/coordinator.rs:140](../../../tests/coordinator.rs#L140), [src/runtime/coordinator.rs:510](../../../src/runtime/coordinator.rs#L510), [src/persistence/repository.rs:179](../../../src/persistence/repository.rs#L179)). Its failure path logs without making the test fail. That invocation is retained privately but is **not isolation evidence**. The existing user-state file had a modification time predating that run; no successful write was observed. The strict rerun created the placement file only inside its private state directory, and the existing file's inode/mtime/size remained unchanged during the rerun. Do not advertise ordinary unisolated test execution as non-mutating. See C19.

Pinned SCTK 0.21.1 source was inspected to avoid false defects: its layer-shell dispatch acknowledges configure before the application callback, and its layer-role Drop precedes its owned surface Drop. Those dependency mechanisms are source evidence, not new native-wire observations.
