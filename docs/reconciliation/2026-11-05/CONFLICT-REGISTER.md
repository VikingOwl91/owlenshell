## Resolution policy

All resolutions are recommendations, not authorized implementation. Where behavior changes user intent, focus, service ownership, process authority or schema compatibility, obtain the named maintainer decision first. The proposal closes no runtime gate by renaming a test or weakening expected behavior. Unsupported observations stay UNVERIFIED/BLOCKED.

No accepted ADR or historical report is edited by this reconciliation. On later documentation cleanup, mark normative targets, old stage plans and experimental records explicitly; do not delete older failures, promote exploratory data or reinterpret prior NO-GOs.
