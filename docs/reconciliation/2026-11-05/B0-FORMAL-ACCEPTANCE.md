## Authority and meaning of acceptance

[MDR-0001](MAINTAINER-DECISIONS.md) records D01–D11 approved in principle and P01–P11 approved policy. The maintainer has now additionally approved **Nested Niri as the primary B1 validation strategy**. That strategy selection supersedes only the earlier “strategy unselected” planning status; it does not select undocumented configuration, establish a running private environment or authorize execution. All earlier documents remain unchanged historical inputs.

Accepting B0 would accept the proposed invariant specifications and their milestone prerequisites. It would not mean code satisfies them, the independently reviewed docs prove runtime safety, B1 is authorized, Gate P passed, or portability/renderer qualification completed. [Accepted ADR-0006](../../ADR/0006-renderer-selection.md) remains unchanged. Slint is the initial renderer, native authority remains Core/SCTK, and no renderer plugin runtime is proposed.

## Source conformance and remaining blockers

All clauses are consistent with approved direction on static review; **current implementation is not conformant merely because this checklist exists**. Canonical examples: [Coordinator lifecycle](../../../src/runtime/coordinator.rs#L260) discards tokens; [pump](../../../src/runtime/coordinator.rs#L584) reconciles before queued lifecycle drain; [pending input](../../../src/platform/wayland.rs#L33) is HostId-bound; [retire](../../../src/platform/surface_manager.rs#L380) drops native before registry invalidation; [main UI callbacks](../../../src/main.rs#L94) directly mutate/project; [clock text](../../../src/runtime/clock_widget.rs#L40) is Slint-specific. These are B1 work, not new runtime failures or contract blockers. Existing session hooks are not a complete shutdown state machine.

The [all-fifteen gap disposition](B0-GAP-DISPOSITION.md) remains valid with the new Nested-Niri strategy approval overlay. G03/G04/G14 have concrete reviewable specifications. G01 exact environment/config/execution binding, B1 G02 bounds/capture, and actual G05 capability evidence remain execution prerequisites. Later G06–G13/G15 mechanisms must be closed by their named milestones; policy approval does not close them. All nineteen conflict findings remain OPEN; no historical evidence or accepted ADR is modified.
