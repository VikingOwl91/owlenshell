## Implementation and boundaries

Core retains its real WaylandPlatform/SCTK connection and event source, SurfaceManager output/layer/configure/generation policy, Coordinator/domain state and sole per-generation presenter. Slint uses the existing software/shm path; egui uses its exclusive native wgpu presenter. No wayapp, replacement event loop or generalized scheduling/plugin framework is added.

The narrow UiRuntime boundary adds optional next-deadline and process-timers hooks. Software hosts expose native attachment and dirty-state queries. `render_bridge.rs` retains concrete Slint timer/animation functions and the historical legacy timeout API; the isolated runner uses the new optional deadline without a fallback poll. `wayland.rs` notifies the host of native attachment outside the manager borrow. `surface_manager.rs` adds configure, frame-callback and successful client-submission traces, without changing native scheduling/presenter gates.

The isolated `experiment/functional-parity/src/main.rs` replaces its 25ms command-file poll with one owned nonblocking FIFO watched by calloop Generic. FD/device/inode, ownership, read access, nonblocking and start handshake are checked; there is no fallback. One dynamically armed earliest timer combines domain/toolkit deadlines; an arm identity rejects stale callbacks. Renderer work runs before the Coordinator pump; queued UI actions still drain after that pump. Current/configured/visible/dirty/frame-pending gates control immediate follow-up. Graceful quit and EOF cancel deadlines, retire native/presenter resources and unregister UI.

`slint_ui.rs` owns cancellable SingleShot timers with weak host ownership and native-token/ticket guards. `egui.rs` and `gpu.rs` preserve ROOT repaint delays and tag callbacks with token/pass/thread through calloop, including real cross-thread wakeups. GPU configure occurs on changed extent, and RawInput uses monotonic time. `schedule.rs` is a finite fixture clock and small eligibility/deadline helpers, not a general scheduler. `model.rs` supplies fixed UTC base plus actual elapsed time through ClockWidgetController. The Slint fixture and egui scene add the same small visible timer cue. Root manifests/locks and production composition are unchanged.

## Input and focus regression

The existing adopted S2 suite was rerun on the S3 implementation, without changing S2 assertions or the User-Open Focus product decision. Both runs completed with **87 PASS / 0 FAIL / 4 UNVERIFIED**, exit0 and empty cleanup errors. Each accepted exactly four clock Toggle and four calendar Hide actions, observed seven native/Core/UI focus states, and destroyed six native lifetimes. Raw `s2-checks.json`, `focus-observations.json`, input logs and domain snapshots are retained under `runs/*-input-01/`. S3's `month` command is a domain navigation trigger, not a physical scroll test; the separate S2 run supplies native pointer, keyboard, scroll and focus sequences.

The historical four S2 UNVERIFIED cases remain native autorepeat, zero-delta delivery, unsolicited/background mapping and immediate erasure of private Core caches. A current focus getter returning None does not establish literal cache erasure. No cross-compositor grant policy, fractional-scale/multiple-output, device recovery or S4–S6 claim follows.
